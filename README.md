
# EduTrack – Student Marks Management System

EduTrack is a responsive student marks management dashboard built using HTML, CSS, and JavaScript. It helps users add multiple students, calculate academic performance, and manage results through a simple interface.

## Features

- Add and manage multiple student records
- Student name and roll number validation
- Six-subject marks entry
- Automatic total and percentage calculation
- Pass/Fail result calculation
- Search students by name or roll number
- Filter students by result status
- Sort student records
- Delete individual student records
- Clear all student records
- Export results as CSV
- Responsive user interface
- Dashboard statistics

## Result Calculation

- Maximum marks: 600
- Minimum passing marks: 50 in each subject
- A student passes only when they score at least 50 in all six subjects.
- Percentage = (Total Marks / 600) × 100

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/shareen2006/EduTrack-Student-Marks-Calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## Data Storage

Student records are stored temporarily in browser memory. Refreshing the page clears the records. Use the CSV export feature to save results.
